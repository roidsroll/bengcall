## About BengCall

**BengCall** adalah platform manajemen bengkel terintegrasi yang menggabungkan sistem reservasi layanan (*booking*) dan *e-commerce* suku cadang. Dibangun dengan fokus pada kemudahan transaksi antara pemilik kendaraan dan pengelola bengkel.

### Fitur Utama:
- **Automatic Stock Management**: Stok berkurang otomatis saat ada penjualan sparepart.
- **Service Booking System**: Antrean servis yang teratur dan transparan.
- **Comprehensive Dashboard**: Monitoring transaksi dan arus kas bengkel.

## Tech Stack

- **Backend/Frontend:** Laravel & Blade/Livewire
- **Styling:** Tailwind CSS
- **Database:** MySQL
- **Server Management:** PM2 & Windows Server
